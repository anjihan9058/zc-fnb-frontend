# 모바일 채팅·근무표 검토 화면 수정

2026-10-27 사용자가 제공한 iPhone 화면과 소스를 기준으로 수정했습니다. 실제 휴대폰·브라우저 실행, 테스트, 타입 검사, 빌드는 수행하지 않았습니다. 소스 반영에는 새 빌드가 필요합니다.

## 모바일 채팅

- 검색 입력 글자 크기를 16px로 지정했습니다. 작은 입력 글자로 인한 iOS 자동 확대를 피하고, 사용자의 수동 확대는 제한하지 않습니다.
- 검색창 포커스와 메시지 전송 후 포커스는 `preventScroll`을 사용합니다.
- 채팅은 visualViewport의 높이와 offsetTop을 함께 반영합니다. 기존 높이만 적용하던 방식에서 키보드가 열리면서 화면이 이동하는 경우를 보완했습니다. resize·scroll·focus 변경을 한 프레임에 묶어 처리합니다.
- 모바일 채팅 문서의 바깥 스크롤을 고정하고 대화 영역만 스크롤합니다. 키보드가 열린 동안 하단 safe-area 중복 여백을 줄입니다. Android의 `interactive-widget=resizes-content`도 viewport에 추가했습니다.
- + 버튼, 입력칸, 이모지, 전송 버튼에 고정된 버튼 크기와 그리드 정렬을 적용했습니다. 검색·메뉴 아이콘도 동일한 터치 영역을 사용합니다.
- 첨부·이모지 패널을 열 때 메시지 키보드를 닫도록 했습니다. 검색 입력도 자동 확대를 위한 최대 배율 제한 없이 사용할 수 있습니다.

## 텍스트 중심 근무표

- 새 근무표 파일/PDF 업로드 진입점을 제거했습니다. 채팅 첨부 메뉴의 근무표는 텍스트 입력창을 열고, 근무표 페이지도 텍스트 입력으로 시작합니다. 영수증 PDF와 일반 채팅 PDF 첨부는 유지합니다.
- 과거 근무표에 저장된 이미지·PDF 원본은 기존 기록에서 열 수 있습니다.
- 근무표 검토는 직원별 합계 카드와 압축된 전체 표에서 시작합니다. 모든 근무를 펼쳐 입력하는 카드 나열을 제거했습니다.
- `전체`, `수정 필요`, `휴게 미정`, `미확인` 필터와 직원 필터를 제공합니다. 날짜·시간·직원 연결·시간 겹침 등 문제가 있는 행만 열어 수정할 수 있습니다.
- 휴게 시간 누락은 공통 설정으로 한 번에 처리합니다. 기본 적용 대상은 미정인 행이며, 전체 덮어쓰기는 별도로 선택해야 합니다. 휴게 시간을 자동으로 0분 처리하지 않습니다.
- 원문과 계산 시간 차이는 직원별 합계에 표시합니다. 원문은 기본적으로 접어 두고 필요할 때 펼칩니다. 서버·원문 경고는 개별 수정 화면에서 확인합니다.
- 전체 검토 체크를 한 번에 적용할 수 있습니다. 직원·시간·휴게의 필수 문제를 해결한 후 사용자가 직접 체크해야 합니다.
- `저장하고 근무표 확정`은 변경된 초안을 저장하고, 반환된 최신 버전으로 확정 요청을 보냅니다. 재시도 시 같은 버전에는 같은 멱등 키를 사용합니다. 서버가 확정 결과를 반환해야 완료로 표시합니다.
- 분석·확정 정책의 최종 권한은 백엔드에 있습니다. 프론트의 필터를 위해 구조화한 오류 분석 함수는 데모 확정에도 공유하여 화면과 저장 규칙을 맞췄습니다.

주요 파일: `src/app/useChatViewport.ts`, `src/pages/ChatPage.tsx`, `src/features/ScheduleEditor.tsx`, `src/features/ScheduleTextDialog.tsx`, `src/shared/schedules.ts`, `src/styles.css`.
