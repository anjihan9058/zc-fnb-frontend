# Vercel 화면 공유 배포

2026-10-29. 저장소의 `vercel.json`에서 Vite, 의존성 설치, 빌드, dist 출력 및 SPA 새로고침 경로를 지정했다.

Vercel에서 GitHub 저장소 `anjihan9058/zc-fnb-frontend`를 Import하고 Deploy한다. 별도 환경변수를 지정하지 않으면 브라우저 로컬 데모로 배포된다. 배포용 계정 연결과 실제 배포 성공은 별도 확인해야 한다.

완료 후 공유할 주소는 Vercel이 발급한 HTTPS 프로덕션 URL이다. 개인 PC의 개발 서버를 켜둘 필요가 없다. 팀원이 GitHub 계정 없이 접속하도록 하려면 프로덕션 배포의 접근 보호 설정을 확인한다.

실제 OCR·팀원 간 공유·로그인·은행 연동은 이번 정적 화면 배포에 포함되지 않는다. 각 브라우저·접속 주소별로 로컬 데이터가 저장된다.

현재 전체 경로의 SPA fallback은 로컬 데모용이다. 실제 백엔드를 연결할 때는 API 주소와 CORS/인증을 설정하고, `/api` 요청이 SPA HTML로 처리되지 않도록 API 프록시 또는 별도 주소를 구성한다.
