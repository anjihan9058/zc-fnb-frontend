# V2 이미지 참고 · 큰 틀 구현

2026-10-28. 사용자가 제공한 로컬 이미지 3묶음을 확인하고, “전부 구현하기보다 큰 틀부터, 팀채팅 유지”라는 최신 요청을 이번 범위로 적용했다.

## 참고 자료 선별

ChatGPT 라이브러리 링크를 열어야만 하는 상태가 아니라 프로젝트 폴더의 실제 PNG·연락판 이미지를 직접 확인했다. 문서의 설명만으로 화면 배치를 추측한 이전 단계와 다르다. 원본들은 참고용으로만 사용하며 앱 배포 자산에 포함하지 않는다.

| 자료 | 채택한 구조 | 이번에 제외한 범위 |
|---|---|---|
| Part1 R005 Navigation, R008 Operations Overview | 흰색 모듈 레일 + 하위 메뉴, 파란 강조색, 2행 바로가기, 요약·활동·근무 패널 | 원본 브랜드, 연결되지 않은 날씨·매출·임의 수치 |
| Part1 R034 Draft Transaction / OCR 연락판 | 왼쪽 정보·품목·활동 탭, 오른쪽 원본 비교 | 거래 기표·지급을 영수증 승인과 동일하게 처리하는 기능 |
| Part2 Cost/Margin 연락판 | 표 중심 원가 조회, 금액·비율 비교, 근거로 이동 | 판매량·실사 자료가 필요한 실제/이론 원가·판매 믹스 |
| Part2 R072 Bank Activity / R073–R083 연락판 | 계좌 선택, 상태 탭, 검색·열 설정, 넓은 표 + 오른쪽 후보·검토 패널 | 실제 은행 로그인·거래 수집·장부 기표·잔액 대사 |
| Part3 Schedule 연락판 | 운영 홈의 직원별 시간대 표시 | 기존 채팅 UI 교체, 일상 대화 전체 분석, 자동 근무 배치 |

구형 데스크톱 화면과 마케팅용 기기 합성 이미지는 주 배치 기준에서 제외했다. 142장을 각각 기능 요구사항으로 취급하지 않는다.

## 변경한 화면

- 공통: 홈·보고서·회계·재고/원가·근무·팀채팅 모듈, 모듈별 하위 메뉴, 접기·펼치기, 모바일 메뉴, 페이지 검색, 영수증/근무 현황 작성 진입.
- 운영 개요 `/dashboard`: 8개 업무 바로가기, 대기 건수, 선택 날짜의 구매·근무 인원, 월 누적 구매, 문서/근무표/입고 대기 업무, 확정 근무 시간대, 식재료 구매 구성.
- 재무 현황 `/dashboard/financial`: 보고서·매입·원가·은행 진입과 월 확정 구매. 매출·손익·은행 수치는 자료 미연결로 표시.
- 매입 업무 센터 `/accounting`: 기존 영수증의 검토 상태별 표, 상세 패널, 원본/OCR 검토 연결. 지급·전표 완료를 뜻하지 않는다.
- 문서 검토: 기존 검토·수정·승인 기능을 유지하며 PC에서 정보와 원본을 비슷한 폭으로 나눔. 모바일 데이터/원본 전환 유지.
- 보고서 `/reports`: 좌측 조건과 우측 결과. 확정 구매 내역은 날짜 기준 실제 기록, 메뉴 원가는 현재 레시피 기준. 손익은 계정 분류 틀만 제공.
- 은행 거래 `/banking`: 최초에는 계좌 미연결·빈 목록. 사용자가 샘플 보기를 선택할 때만 가상 거래 4건 표시. 후보 선택 → 차액 확인 → 검토 → 샘플 연결/해제/제외 가능. 새로고침 시 초기화하며 사용자 구매 데이터·은행·장부를 변경하지 않음.
- 공통 표: 검색, 정렬, 열 표시, 10행 페이지 이동, 행 상세 선택. 저장된 보기·열 순서 조절·일괄 처리는 후속 범위.

## 유지한 차별성

팀채팅 화면·입력창·모바일 키보드 처리는 재설계하지 않았다. 영수증은 유형 지정 없이 첨부한다. 긴 근무 현황은 사용자가 **근무표로 정리**를 선택할 때만 기존 정리 흐름으로 들어간다. 실제 AI/OCR와 팀원 공유는 백엔드 연결 전 상태를 유지한다.

## 이번 단계의 경계

V2 계획 전체 완료가 아니라, 실제 이미지에 근거한 화면 체계와 대표 작업 공간의 첫 구현이다. AP/AR·복식부기·계정과목 관리·실은행 연결·잔액 대사·POS 매출·실제 사용 원가 엔진은 추가하지 않았다. 재무 계산을 임의 구매 합계로 대신하지 않는다. API·인증·사업장 격리·PWA 캐시 정책은 기존 계약을 유지했다.

구매와 문서 집계는 현재 API가 반환하는 기록 범위를 따른다. 서비스가 커지면 전체 건수·보고서·페이지 처리는 서버 집계 및 페이지네이션 계약으로 전환해야 한다.

## 확인 결과

- 자동 테스트: **14개 파일, 131개 통과**. 기존 121개에 금융 화면 복귀 경로 4개, 은행 샘플 보호 3개, 공통 표·은행 UI 상호작용 3개 추가.
- TypeScript `tsc -b` 통과.
- Vite 프로덕션 빌드·서비스 워커 생성 완료. `dist/` 갱신.
- 빌드 경고: Zod 의존성의 주석 제거 안내와 큰 청크 경고(main 약 515KB, 지연 로딩 ExcelJS 약 937KB). 빌드 오류는 아님.
- 브라우저 도구는 로컬 화면 탐색에서 CDP 시간 초과가 발생해 실제 렌더 화면 확인을 완료하지 못했다. 자동 UI 검사는 DOM 동작 확인이며 화면 캡처 검증을 대신하지 않는다.
- 실제 은행·OCR·기기 간 공유·iOS 실기기는 이번 확인 범위가 아님. 확인용으로 시작한 5191 개발 서버는 종료했다.
